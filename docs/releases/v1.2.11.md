# Glance AI 1.2.11

Fresh installations start at **100% opacity** to avoid Windows layered-window rendering overhead while AI replies stream. Saved opacity choices remain unchanged, and the transparency controls still work. The Settings percentage now correctly follows saved settings and shortcut changes.

For an existing installation, choose 100% opacity and restart Glance once. Finish or save any unsent draft before restarting. Electron retains its layered-window state after transparency has been used, so a fresh window is needed to get the normal rendering path.

This mitigates translucency overhead observed during a Gemini lag investigation; provider-side rendering can still cause delays. Native provider UI, sign-in, capture/send controls, shortcuts, and immediate hide/show are preserved.

Version 1.2.10 was not published after verification caught outdated corrupt-settings test expectations. This release includes that performance mitigation and the opacity label correction.

Download **Glance-AI-Setup-1.2.11.exe** or **Glance-AI-Portable-1.2.11.exe**, and verify against **SHA256SUMS.txt**. Builds remain unsigned.
