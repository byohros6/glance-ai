# Glance AI 1.2.9

Glance now checks for newer published GitHub releases automatically after startup and every 12 hours. When an update is available, choose **Download update** or **Later**. Settings also includes **Check for updates** and a download button.

Installer installations get the installer download; portable launches get the portable download. If the matching executable is unavailable, Glance opens that version's release page instead. Download the update, quit Glance, and run the installer or replace your portable executable. Existing settings are retained. Installation remains manual; there is no automatic download or execution.

Checks run in the background with a timeout and request throttling. Offline or rate-limited checks report that updates could not be checked. Only published stable releases in the public repository are eligible; draft and prerelease versions do not trigger prompts.

Includes the 1.2.8 sandboxed upload fix and repository/release improvements. Native provider UI, sign-in behavior, shortcuts, and immediate hide/show remain unchanged.

Download **Glance-AI-Setup-1.2.9.exe** or **Glance-AI-Portable-1.2.9.exe** and verify against **SHA256SUMS.txt**. Windows builds are unsigned.
