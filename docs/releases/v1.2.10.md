# Glance AI 1.2.10

Fresh installations now start at **100% opacity** to avoid the Windows layered-window rendering path while AI replies are streaming. The transparency slider and shortcuts still work, and existing saved opacity choices are retained.

If replies make typing or scrolling sluggish, set opacity to 100% and restart Glance once. Electron keeps the layered-window state after transparency has been used, so a newly created full-opacity window gets the normal rendering path. Restarting can discard an unsent draft; finish or save it first. Click-through can be toggled without permanently adding layered composition to a fresh opaque window.

This patch addresses translucency overhead identified during a lag investigation. Provider-side rendering can still cause delays; this is not a guarantee that every Gemini slowdown is resolved. Native provider UI, authentication, capture/send controls, shortcut defaults, and immediate hide/show remain unchanged.

Download **Glance-AI-Setup-1.2.10.exe** or **Glance-AI-Portable-1.2.10.exe**, and verify against **SHA256SUMS.txt**. Builds remain unsigned.
