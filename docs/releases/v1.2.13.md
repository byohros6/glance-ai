# Glance AI 1.2.13

Gemini replies no longer stall for one to two minutes when you are signed in. Glance now presents a standard Chrome browser identity to Gemini pages. The sign-in flow keeps its existing behavior, and other providers are unchanged.

This release also updates the bundled Chromium runtime to Electron 44.10.1 for the latest security fixes.

Download **Glance-AI-Setup-1.2.13.exe** or **Glance-AI-Portable-1.2.13.exe**, and verify against **SHA256SUMS.txt**. Builds remain unsigned.
