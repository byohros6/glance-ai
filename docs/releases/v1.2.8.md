# Glance AI 1.2.8

This patch preserves the native provider UI and the 1.2.7 sign-in, shortcuts, opacity, click-through, and immediate hide/show behavior.

- Fix the button-triggered upload fallback by restoring its required Electron import.
- Add a sandboxed regression covering file-picker interception and restoration.
- Stabilize native opacity and shortcut test renderer startup/teardown.
- Patch the build-tool cache dependency's high-severity advisory.
- Organize the public repository and add release package verification and checksums.

Download **Glance-AI-Setup-1.2.8.exe** for installation, or **Glance-AI-Portable-1.2.8.exe** to run without installing. Compare the file's SHA-256 hash against **SHA256SUMS.txt**.

Windows executables are unsigned. Provider websites can change; automated tests use local fixtures. Existing accounts and app settings are retained.
